基于 SpringBoot+RAG 的校园参观预约与智能咨询系统

哈尔滨剑桥学院 · 智能科学与工程学院 · 2026 届毕业设计

学生：钟啸林    指导教师：郭旭 副教授

项目简介

面向高校对外开放参观场景的一体化 Web 系统，集成：

  • 访客线上预约参观（注册登录、查看场次、提交预约、订单状态管理）
  • 管理员后台审核管理（场次、预约、访客、公告、知识库）
  • RAG 私有知识库 AI 智能咨询（基于本校文档，杜绝大模型幻觉）
技术栈
层级技术
后端SpringBoot 3.2 + MyBatis-Plus + JWT
前端Vue3 + Element-Plus + Axios + Vite
业务数据库MySQL 8.0（7 张表）
向量数据库Milvus（Docker，768 维，集合 campus_knowledge）
嵌入模型BGE-small-zh（本地）
大模型阿里百炼 DashScope（qwen-plus）
文档解析PDFBox + POI
RAG 编排手写实现（不依赖 LangChain 框架）

原型使用说明

本组原型为中保真原型，所有页面可直接在浏览器打开运行。

  • 使用真实业务文字和模拟业务数据填充，便于对齐设计认知
  • 页面之间支持跳转：点击菜单项/按钮可跳转到对应页面
  • 表单可输入，弹窗可打开/关闭，演示交互逻辑
  • 未纠结精细配色，统一灰度 + 主色调（校园蓝 #409EFF）
  • 开发阶段（Stage2）严格对标此原型实现，禁止私自改页面
