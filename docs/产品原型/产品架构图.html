RAG 核心工作链路（毕设亮点）
① 管理员上传 PDF/Word/TXT 文档
↓
② 后端 PDFBox/POI 解析文本 → 按 500 字 + 100 字重叠分块
↓
③ BGE-small-zh 生成 768 维向量 → 写入 Milvus 集合 campus_knowledge
↓
④ 访客提问 → 问题向量 → Milvus 相似度检索 top-3 文档片段
↓
⑤ 拼提示词（强约束：无内容回固定话术，禁止编造）→ 调阿里百炼 qwen-plus
↓
⑥ 返回答案 → 问答记录存 MySQL ai_chat_record → 前端展示
数据存储分离

MySQL（结构化业务数据）

  1. visitor_user 访客用户
  2. visit_session 参观场次
  3. visit_reservation 预约订单
  4. campus_notice 校园公告
  5. knowledge_doc 文档元数据
  6. ai_chat_record 聊天记录
  7. sys_admin 管理员账号

Milvus（向量数据库）

集合：campus_knowledge

  • vector：768 维 FLOAT_VECTOR
  • doc_id：关联 knowledge_doc 主键
  • chunk_text：原始文本块

检索策略：相似度 top-3 检索，按 doc_id 删除保证一致性
