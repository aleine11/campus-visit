# 前端原型结构与页面设计文档

> 基于 SpringBoot+RAG 的校园参观预约与智能咨询系统
>
> 哈尔滨剑桥学院 · 智能科学与工程学院 · 2026 届毕业设计

---

## 一、文档说明

本文档定义前端项目的整体结构、全部页面清单、每个页面的元素与交互、统一样式规范、路由跳转与权限控制。

**适用范围**：访客前台 + 管理员后台（共用一个 Vue3 项目，通过路由区分）。

**强制约束**：开发阶段（Stage2）必须 100% 对标本文档页面清单、组件结构、样式规范，禁止私自新增页面、改动布局、改换 UI 库。

**目录作用解释**
- `api/`：每个业务模块一个文件，统一 export 函数返回 request 调用，便于复用
- `components/`：跨页面复用的公共组件，避免重复代码
- `layouts/`：与 `views/.../Layout.vue` 等同，统一放在 layouts 下更清晰（开发时可选其一）
- `store/`：用户登录态、AI 会话状态等全局状态放这里
- `utils/`：工具函数与常量，方便统一维护
- `views/`：按"角色/模块"二级目录组织页面，导航清晰

## 四、每页详细设计

### F1 访客首页 `/visitor/home`

**用途**：访客第一眼看到校园，含校园简介、环境图、最新公告、可预约场次入口。

**页面元素**：
1. 顶部 Hero 横幅：校园风光图 + 校名"哈尔滨剑桥学院 · 智能科学与工程学院" + 一句标语
2. 校园简介区块：约 200 字文字 + 2~3 张环境配图
3. 最新公告区块：3 条最新公告卡片（标题 + 时间 + 摘要），点击跳详情
4. 可预约场次区块：3 条近期场次卡片（日期、时段、剩余名额），点击跳场次列表
5. AI 咨询入口：右下角悬浮按钮（全局组件，每页都显示）

**权限**：未登录可看，但点击"立即预约"或"AI 咨询"时跳登录页。

---

### F2 校园公告列表 `/visitor/notice`

**用途**：分页浏览已发布公告。

**页面元素**：
- 顶部面包屑"首页 / 校园公告"
- 公告列表（每条：标题、发布时间、摘要 80 字），点击进详情
- 底部分页（每页 10 条）

**权限**：未登录可访问。

---

### F3 公告详情 `/visitor/notice/:id`

**用途**：查看单条公告全文。

**页面元素**：
- 标题、发布时间、正文（支持简单富文本展示）
- 底部"上一条/下一条"导航

**权限**：未登录可访问。若公告 id 不存在或未发布，跳 404。

---

### F4 可预约场次列表 `/visitor/session`

**用途**：列出所有可预约场次（自动过滤过期、下架、名额满）。

**页面元素**：
- 顶部筛选：日期范围选择、时段筛选
- 场次卡片列表（每张卡片：参观日期、时段、剩余名额/总名额、立即预约按钮）
- 名额为 0 的场次卡片置灰，按钮变"已满"
- 底部分页

**权限**：未登录可浏览。点击"立即预约"跳登录。

---

### F5 预约提交页 `/visitor/reservation/submit/:sessionId`

**用途**：访客填写预约表单。

**表单字段**：

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 参观场次 | 只读展示 | - | 显示日期、时段、剩余名额 |
| 真实姓名 | 文本输入 | 是 | 2~10 字 |
| 联系手机号 | 文本输入 | 是 | 11 位手机号正则 |
| 参观人数 | 数字输入 | 是 | 1~剩余名额（最大 50） |
| 参观事由 | 多行文本 | 是 | 5~200 字 |

**操作按钮**：提交预约 / 返回场次列表

**业务校验**（前端先校验，后端再校验）：
- 当前访客是否已预约过该场次（重复预约拦截）
- 场次剩余名额是否足够
- 场次是否过期/下架

**权限**：必须登录。

---

### F6 我的预约 `/visitor/reservation/list`

**用途**：查看个人全部预约订单。

**页面元素**：
- 状态筛选 tab：全部 / 待审核 / 通过 / 驳回 / 已取消
- 订单列表（场次日期、时段、参观人数、状态标签、提交时间）
- 每条订单可"查看详情"或"取消"（仅待审核订单可取消）

**权限**：必须登录。

---

### F7 预约详情 `/visitor/reservation/:id`

**用途**：查看单条订单完整信息 + 取消操作。

**页面元素**：
- 订单信息：场次日期、时段、参观人数、手机号、参观事由
- 审核信息：状态、审核人（管理员）、审核时间、驳回原因（如有）
- 时间线：提交时间 → 审核时间 → 取消时间（如有）
- 操作按钮：仅当状态=待审核时显示"取消预约"

**权限**：必须登录，且订单 visitor_id 必须等于当前用户。

---

### F8 AI 历史会话 `/visitor/chat/history`

**用途**：访客查看历史问答记录、清空会话。

**页面元素**：
- 顶部"清空全部"按钮（带二次确认弹窗）
- 会话列表（按时间倒序）：每条显示用户问题 + AI 回答 + 时间
- 分页加载

**权限**：必须登录。

---

### F9 个人中心 `/visitor/profile`

**用途**：修改个人信息 + 修改密码。

**两个 Tab**：
1. 个人信息 Tab
   - 真实姓名（可改）
   - 联系手机号（可改）
   - 用户名（不可改）
   - 注册时间（只读）
2. 修改密码 Tab
   - 原密码、新密码、确认新密码
   - 校验：原密码必填；新密码 6~20 位含字母数字；两次输入一致

**权限**：必须登录。

---

### F10 登录页 `/login`

**用途**：访客 + 管理员统一登录入口，后端按账号类型返回不同角色。

**页面元素**：
- 居中卡片：标题 + 用户名/密码输入 + 登录按钮
- 底部链接：注册账号 / 管理员入口（实际跳同一个登录，仅文案不同）

**业务逻辑**：
- 提交后端，后端返回 token + role（visitor/admin）
- role=visitor → 跳 `/visitor/home`
- role=admin → 跳 `/admin`
- 账号冻结 → 弹提示"账号已被冻结"

---

### F11 注册页 `/register`

**用途**：访客自助注册。

**表单字段**：

| 字段 | 必填 | 校验 |
|------|------|------|
| 用户名 | 是 | 4~20 位字母数字下划线，唯一 |
| 密码 | 是 | 6~20 位含字母数字 |
| 确认密码 | 是 | 与密码一致 |
| 真实姓名 | 是 | 2~10 字 |
| 联系手机号 | 是 | 11 位手机号 |

**业务逻辑**：注册成功后跳登录页，不自动登录。

---

### F12 AI 悬浮咨询窗（核心组件）`components/AiFloatChat.vue`

**用途**：访客登录后可在任意访客前台页面右下角打开 AI 咨询。

**页面元素**：
- 右下角圆形悬浮按钮（绿色，写"AI 咨询"）
- 点击展开右侧抽屉（宽 380px）
  - 顶部：标题"校园智能助手" + 折叠按钮 + 清空当前会话
  - 中部：聊天消息列表（用户消息右气泡蓝色、AI 回答左气泡灰色）
  - 底部：输入框 + 发送按钮 + "Enter 发送，Shift+Enter 换行"
- AI 回答时显示"思考中..."加载动画
- AI 回答附带"参考来源"标签（来自哪个文档）

**业务约束**：
- 未登录点击悬浮按钮 → 弹"请先登录"提示 → 跳登录页
- 已登录可发问，未登录访问此组件不显示按钮

**交互示例**：
```
访客：参观校园需要预约吗？
AI：需要预约。请在"参观预约"页面选择场次并填写信息...
    [参考来源：校园参观须知.pdf]

访客：能停车吗？
AI：校园开放访客停车场，位于东门北侧...
    [参考来源：入校须知.docx]
```

### A1 后台首页（看板）`/admin`

**用途**：管理员登录后第一屏，关键数据看板。

**4 个数字卡片**：
1. 今日新增预约数
2. 待审核订单数
3. 访客总数
4. AI 问答总次数

**1 个图表**：近 7 天每日预约数折线图（ECharts）

**1 个列表**：最近 5 条待审核订单（场次日期、访客姓名、人数、提交时间、审核按钮）

---

### A2 参观场次管理 `/admin/session`

**用途**：管理员维护参观场次。

**列表**：分页表格，字段：场次ID、参观日期、时段、最大容纳人数、已预约人数、状态（开放/下架）、创建时间、操作

**操作按钮**：
- 新增场次（右上角按钮）→ 弹窗
- 编辑 → 弹窗
- 下架/上架（切换状态）
- 删除（仅当 used_people=0 才可删）

**新增/编辑弹窗表单**：

| 字段 | 必填 | 校验 |
|------|------|------|
| 参观日期 | 是 | 日期选择器，禁选过去日期 |
| 时段 | 是 | 文本如 "09:00-11:00"，或时段选择器 |
| 最大容纳人数 | 是 | 1~500 |
| 状态 | 是 | 开放/下架 |

---

### A3 预约订单审核 `/admin/reservation`

**用途**：分页查询预约、审核通过/驳回。

**筛选条件**：访客姓名模糊、状态、提交时间范围

**列表字段**：订单ID、场次（日期+时段）、访客姓名、参观人数、手机号、参观事由、状态、提交时间、审核操作

**审核操作**：
- 待审核订单：显示"通过"和"驳回"两个按钮
- 已审核订单：显示审核结果（通过/驳回 + 驳回原因），按钮禁用

**驳回弹窗**：必须填写驳回原因（5~200 字），否则禁用提交

---

### A4 访客用户管理 `/admin/visitor`

**用途**：管理员管理访客账号。

**列表字段**：访客ID、用户名、真实姓名、手机号、状态（正常/冻结）、注册时间、操作

**操作**：
- 冻结/解冻（按钮根据当前状态切换文字）
- 查看该访客全部预约（跳转预约审核页 + 自动筛选该访客）

---

### A5 校园公告管理 `/admin/notice`

**用途**：管理员维护公告。

**列表字段**：公告ID、标题、状态（未发布/已发布）、发布时间、创建时间、操作

**操作**：新增、编辑、发布、下架、删除

**新增/编辑弹窗**：

| 字段 | 必填 | 校验 |
|------|------|------|
| 标题 | 是 | 1~100 字 |
| 正文 | 是 | 1~10000 字，支持简单换行 |

### A6 RAG 知识库文档管理 `/admin/knowledge` （核心模块）

**用途**：管理员上传、查看、删除校园知识库文档。

**列表字段**：文档ID、文件名、文件类型、上传时间、向量块数、操作

**操作**：
- 上传文档（右上角按钮）→ 弹窗选择 PDF/TXT/Word，上传后后端自动解析分块入库
- 删除文档（二次确认，提示"将同步删除 Milvus 中全部向量"）
- 重新解析（备用，若向量数据丢失可重建）

**上传弹窗**：
- 文件选择（限制 pdf/txt/docx，单文件最大 50MB）
- 上传进度条
- 后端处理时显示"文档解析+向量化中..."动画
- 成功后列表自动刷新，新文档显示

**风险提示**：文档删除会同步删除向量，操作不可逆，弹窗二次确认。

## 七、页面权限控制

### 7.1 三种角色权限

| 路由 | 访客 | 管理员 | 未登录 |
|------|------|--------|--------|
| `/visitor/*`（除预约、个人中心、AI 历史） | ✅ | ✅ | ✅ |
| `/visitor/reservation/*` `/visitor/profile` `/visitor/chat/history` | ✅ | ❌ | 跳登录 |
| `/admin/*` | ❌（跳 403） | ✅ | 跳登录 |
| `/login` `/register` | ✅ | ✅ | ✅ |

### 7.2 路由守卫实现

- 全局前置守卫 `router.beforeEach`：
  1. 检查目标路由 `meta.requiresAuth`
  2. 检查 `meta.role` 是否匹配当前角色
  3. 不匹配跳 403 或登录页

- token 检查：
  - `localStorage.getItem('campus_token')` 存在 → 已登录
  - 每次路由切换校验 token 是否过期（前端读 JWT exp 字段）
  - 后端 401 拦截器统一处理：清 token + 跳登录

## 八、页面状态规范

### 8.1 加载中
- 列表加载：表格显示"加载中..."骨架
- 弹窗提交：按钮 loading + 禁用
- AI 回答：显示 3 个跳动的圆点动画 + "AI 思考中..."

### 8.2 空数据
- 表格无数据：`<el-empty description="暂无数据" />`
- 搜索无结果：`<el-empty description="未找到匹配数据" />`

### 8.3 报错
- 网络错误：`ElMessage.error('网络异常，请稍后重试')`
- 业务错误：根据后端 code 显示对应 msg
- 接口 500：跳 `/error` 页

### 8.4 无权限
- 访问无权限路由：跳 `/forbidden`
- 提交无权限操作：`ElMessage.warning('无权限操作')`
